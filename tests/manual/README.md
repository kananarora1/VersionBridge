# Mandatory manual end-to-end checkpoints

Follow the complete procedures and pass/fail gates in the [development plan](../../docs/DEVELOPMENT_PLAN.md). Record each attempt using [the checkpoint template](CHECKPOINT_TEMPLATE.md), copied into `records/` with a name such as `P1-YYYY-MM-DD-attempt-01.md`.

P0 covers isolation and source integrity; P1 analysis; P2 evidence; P3 selected patches; P4 complete verification; P5 the release-candidate drill. No checkpoint has passed yet. Record failure and remediation rather than waiving a gate. Commit only sanitized evidence or artifact references, never credentials or private source dumps.
