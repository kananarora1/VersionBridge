# Architecture decision records

Copy [0000-template.md](0000-template.md) to the next numbered file, such as `0001-control-plane-stack.md`, and record the decision before adding the corresponding framework or infrastructure.

Initial decisions should cover the runtime stack, parser, persistence/index, verifier isolation, official-source provenance, and model-provider data handling. Mark decisions as proposed until agreed and implemented. The template is not an accepted decision.
