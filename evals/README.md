# Evaluation

- `datasets/`: versioned gold labels and repository-level development/holdout splits.
- `experiments/`: reproducible baseline, path-text, and hierarchy-expansion configurations.
- `reports/`: reviewed, redacted aggregate results and promotion decisions.

Track analysis precision/recall, evidence Recall@k/MRR, citation correctness/version matching, apply rate, verified test-pass rate, abstention, latency, and model/retrieval costs. Split by repository and keep related mutations in the same split. Generated raw runs belong outside Git. Empty directories do not represent evaluated systems or measured results.
